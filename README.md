# AiLive

Public release repository for **AiLive**, a Player2-powered mod for **X4: Foundations**.

## Release status

No playable build has been published in this repository yet. Packaged downloads and version-specific installation instructions will appear in [Releases](https://github.com/KennyG1990/AiLive/releases).

## Downloads

When a release is available, download the mod ZIP attached under that release's **Assets**. GitHub's automatically generated **Source code** archives contain this repository's documentation, not the playable mod.

Each release will document its supported X4 version, requirements, installation steps, and known limitations.

## Player2

AiLive uses [Player2](https://player2.game). Follow the setup instructions included with the version you download.

## Repository scope

This repository contains public release documentation and packaged mod downloads. Development source and history are maintained separately.
