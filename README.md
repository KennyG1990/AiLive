# AiLive

Public release repository for **AiLive**, a Player2-powered mod for **X4: Foundations**.

## Release status

**[AiLive 2.1.0 RC1 — The Galaxy Has Something to Say](https://github.com/KennyG1990/AiLive/releases/tag/v2.1.0-rc.1)** is available as a public prerelease. Read the release page for the detailed feature overview, implemented-versus-upcoming roadmap, installation instructions, and known limitations.

## Downloads

Download **[x4_ai_influence.rar](https://github.com/KennyG1990/AiLive/releases/download/v2.1.0-rc.1/x4_ai_influence.rar)** from RC1. A SHA-256 checksum is provided in the release assets. Extract the included `x4_ai_influence` folder into your X4 `extensions` directory, following the release instructions. GitHub's automatically generated **Source code** archives contain this repository's documentation, not the playable mod.

This is an experimental release candidate. Back up your save and use a separate test save. Package integrity and manifest checks passed; this exact archive has not been freshly qualified end to end in game.

## Player2

AiLive uses [Player2](https://player2.game). Keep Player2 running and signed in. Follow the setup instructions on the release page; the bundled README has older download links.

## Repository scope

This repository contains public release documentation and packaged mod downloads. Development source and history are maintained separately.
